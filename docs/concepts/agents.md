# AI agents

## Overview

A SupportAI agent is an AI-powered support assistant that can
understand user questions, retrieve relevant information, and
generate responses.

## Agent components

A SupportAI agent consists of several components:

- Instructions that define the agent's behavior
- Knowledge sources that provide information
- Workflows that define how tasks are handled
- Integrations that connect the agent to external systems

## How agents work

When a user sends a message, the agent processes the request,
identifies relevant information, and generates a response based on
its configuration and available knowledge.

## When to use an AI agent

Use an AI agent when you need to:

- Automate repetitive support conversations
- Answer questions using organizational knowledge
- Guide users through support workflows
- Integrate AI-powered support into an application
