# Introduction

Welcome to the SupportAI documentation.

SupportAI is an AI-powered customer support platform that helps
organizations automate customer conversations, manage knowledge,
and build AI-powered support workflows.

## What you can do with SupportAI

With SupportAI, you can:

- Create AI support agents
- Connect knowledge sources
- Configure agent workflows
- Integrate SupportAI with your applications
- Monitor and troubleshoot AI agents

## Who is this documentation for?

This documentation is intended for:

- Developers integrating SupportAI into their applications
- Administrators configuring SupportAI
- Technical teams managing AI agents
- Product and support teams working with SupportAI

## Get started

If you're new to SupportAI, start with the following steps:

1. Create a SupportAI account.
2. Create your first AI agent.
3. Configure a knowledge source.
4. Test your agent.
5. Integrate the agent with your application.

## Next steps

After completing the getting-started guide, explore the
conceptual documentation to understand how SupportAI works.

You can then move on to the API documentation and
developer guides.

## Example API request

You can use the SupportAI API to interact with your AI agent.

```bash
curl https://api.supportai.example/v1/agents \
  -H "Authorization: Bearer YOUR_API_KEY"
```
## Prerequisites

Before you get started, make sure you have:

- A SupportAI account
- An API key
- Access to the SupportAI dashboard
- Basic knowledge of REST APIs

## Your first agent

After creating your SupportAI account, create an AI agent from the
SupportAI dashboard.

1. Open the **Agents** page.
2. Click **Create Agent**.
3. Enter a name for your agent.
4. Select a knowledge source.
5. Click **Create**.

After your agent is created, you can test it from the agent
playground.

For information about authenticating API requests, see the
[API authentication guide](../api/authentication.md).
