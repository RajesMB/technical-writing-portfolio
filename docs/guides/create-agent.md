# Create an AI agent

## Before you begin

Make sure you have:

- A SupportAI account
- Access to the SupportAI dashboard
- At least one knowledge source

## Steps

1. Open the **Agents** page.
2. Click **Create Agent**.
3. Enter a name for the agent.
4. Add the agent instructions.
5. Select a knowledge source.
6. Click **Create**.

## Test the agent

After creating the agent, open the agent playground and send a test
message.

Verify that the agent returns a response based on the configured
instructions and knowledge source.

## Next steps

After creating your agent, you can configure additional knowledge
sources or integrate the agent with your application.
